# Audits

Per-author and per-section content audits. Each pass produces a
markdown file (and optionally a JSON companion) named
`audit-<scope>-YYYY-MM-DD.md`.

Recent passes:

- `audit-ad-2026-04-25.md` — first author-by-author file audit (A–D slugs)
- `bi-briefs-authorship-2026-04-26.md` — Budapest Institute briefs check
- `audit-content-2026-05-09.md` — gap stocktake across all econ papers (English-only fields)
- `audit-content-chokepoints-2026-05-09.md` — items the gap-fill pass could not draft confidently
- `audit-content-hardlist-2026-05-09.txt` — the 91 papers without abstract grouped by lead author
- `audit-content-2026-05-09.json` — per-paper machine-readable status table

Audits stay in this folder after they're acted on — they're the historical
record of what the catalogue looked like at a given point.
