## 1. Project summary

Magyar Közgazdászok (`gbekes/magyar-kozgazdaszok` on GitHub) is the
static, bilingual catalogue of peer-reviewed research by top Hungarian
economists, framed for policymakers + journalists + interested public.
Auto-deploys via GitHub Pages on push to `main`. As of this handover
the catalogue carries **106 authors and 855 papers**, plus 159 press
items and 35 policy items.

### 3e. AI semantic search — design phase

Three docs added in `search/` (commit `3e30b0b`):

- `ai-search-primer-for-gabor.md` — plain-language explainer
- `ai-search-claude-code-plan.md` — 6-phase implementation spec
- `ai-search-audit.md` — Phase 0 output: repo state, paper-field
  coverage, locked-in decisions (OpenAI `text-embedding-3-large`
  1024d, Cloudflare Workers, indexed text = abstract + summary_en +
  topics)

**Then the editor flagged Pagefind** (https://pagefind.app/) as
a simpler alternative — static-site search library, no backend.
Trade-off discussion is in the chat history but not yet a doc:

- Pagefind: zero backend, zero cost, keyword + filter, no semantic
- Embeddings: real semantic match + cross-lingual, but needs Worker +
  API key + ongoing cost

**No decision yet.** The editor said "Let me think more". `search/`
folder stays as background design. If editor picks Pagefind, the
embeddings docs become v2-exploration; if embeddings, Pagefind is
a possible complement.
