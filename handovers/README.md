# Handover documents

Pickup notes written when a Claude Code session approaches the
~88 % context-window limit. Each file lets a fresh session read in
and continue the work cold. Convention defined in `CLAUDE.md`.

Filename: `handover-YYYY-MM-DD.md`. Newest at the bottom of an
`ls`. Old handovers are kept for archival reference; only the most
recent one is normally needed.
