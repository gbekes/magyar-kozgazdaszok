## One-paragraph project summary

**Magyar Közgazdászok** — static catalogue of peer-reviewed research,
policy work, and press output by Hungarian economists, framed for
Hungarian policymakers. HTML + vanilla JS + CSS, JSON data layer,
GitHub Pages deploy on push to `main`. Custom domain
`magyar-kozgazdaszok.hu`. The catalogue distinguishes Research /
Policy / Press; the public site is bilingual (every page mirrored
under `hu/`). Admission rule SPEC §1.2 (AND): ≥1 tier A/B + ≥3
international good journals (whitelisted in `data/journals.json`,
excluding the `B-hu` Hungarian-only tier). Auto-push to `main` is
enabled for this repo per a saved memory note — every commit goes
straight live.

## Memory rules worth re-reading

These three rules are saved in
`C:\Users\bekes\.claude\projects\C--Users-bekes-Documents-GitHub-da-w-ai\memory\`:

1. **`feedback_push_magyar_kozgazdaszok.md`** — Auto-push to main is
   enabled for this repo. Every commit goes live on GitHub Pages
   immediately. Do not skip the push step.

2. **`feedback_no_fabrication.md`** — Never create paper stubs from
   memory or pattern-matching. Always verify titles, coauthors,
   journal, year against IDEAS / Scholar / CV first. ~29% of
   unverified stubs in earlier sessions had errors; this rule prevents
   that drift. Applies equally to coauthor names and journal names —
   not just titles.

3. **`feedback_bio_style.md`** — Author bios follow a fixed structure:
   (1) current position, (2) **one** umbrella research-focus sentence,
   (3) top **2–3** journals (not 5–6), (4) other stuff. Target ~80–110
   words. No laundry lists of subtopics or 6-journal lists. The
   Berlinger and Kónya entries are the reference examples.

## Useful scripts in `scripts/`

- `apply_drafts.py <draft.json>` — applies EN drafts (and tag
  validation) to paper JSONs. Run from repo root.
- `apply_summaries_hu.py <hu.json>` — same, for Hungarian
  translations.
- `cross_check.py` — validate tags / DOIs / refs across the whole
  catalogue. Outputs `pdf-lists/cross-check-report.md`.
- `.claude/skills/audit-author/bulk_audit.py <slug...>` — per-author
  audit (admission, missing fields, draft status).
- `.claude/skills/audit-author/bulk_audit_summary.py [--pattern X]` —
  ranked table across many authors.
- `build.py` — refreshes `data/index.json` after any data change.
  Run before commit.
