## One-paragraph project summary

**Magyar Közgazdászok** — static catalogue of peer-reviewed research,
policy work, and press output by Hungarian economists, framed for
Hungarian policymakers. HTML + vanilla JS + CSS, JSON data layer,
GitHub Pages deploy on push to `main`. Custom domain
`magyar-kozgazdaszok.hu` (live since `86c1665`). The catalogue
distinguishes Research / Policy / Press; counter chips and bilingual
title/title_hu conventions are in place. The current bottleneck is
populating `data/papers/<slug>.json` `abstract` fields so a later
session can draft `summary_en` / `summary_hu`. Per
`pdf-lists/_all.csv`, ~247 papers needed PDFs/abstracts as of
2026-04-27; this session knocked out 88 (~36%).
